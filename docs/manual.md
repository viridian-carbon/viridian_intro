# 使用手册 — 数据统计配置指南

## 概述

融禹系统的能耗与碳排放数据统计基于「**表计 → 区域 → 因子**」三层配置体系。正确完成这三步基础设置后，系统即可自动采集、折算并汇总出多维度的能耗与碳排报表。

本文档按配置顺序逐一说明每个步骤的作用和操作方法，最后汇总介绍整体的统计计算逻辑。
## 1. 表计设置

### 1.1 什么是表计

表计是数据统计的**最底层数据源**。系统通过智能仪表（水表、电表、天然气表、压力表等）实时采集能源消耗数据，所有能耗分析都建立在表计读数之上。

### 1.2 表计的层级结构

表计采用**分级编码体系**，形成树形层级：

```
I-01 总进水表
├── II-01 车间A进水表
│   ├── III-01 产线1水表
│   └── III-02 产线2水表
└── II-02 车间B进水表
```

- **上级表计**的读数应等于所有**直属下级表计**读数之和（允许一定误差）
- 若存在未安装子表的支路，可创建**虚拟表**（计算公式表）来补全平衡

### 1.3 表计的关键字段

| 字段 | 作用 | 对统计的影响 |
|------|------|-------------|
| **表计名称** | 标识设备 | 在报表和图表中显示 |
| **类型** | 水/电/气/压力等 | 决定数据归类到哪个能源品种 |
| **倍率** | 计量倍率系数 | 实际用量 = 表计读数差 × 倍率 |
| **启表底数** | 初始读数 | 首次统计时的基准值 |
| **引擎** | 采集协议/方式 | 决定数据如何自动获取 |
| **父级表计** | 层级归属 | 决定在设备树中的位置 |

### 1.4 配置入口

进入 **管理中心 → [设备管理](/pageFunction/ManagementCenter/DeviceManagement)**，在左侧设备树中新增或编辑表计。

> 💡 **提示**：表计配置完成后，还需要将其**绑定到区域**，才能在区域维度的报表中看到数据。详见下一节。

## 2. 区域设置

### 2.1 什么是区域

区域代表企业的**物理空间层级**，是能耗数据**按空间维度汇总**的基础。一个区域可以绑定多块不同类型的表计。

### 2.2 区域的层级结构

```
公司总计（根区域）
├── 生产区
│   ├── 一车间
│   └── 二车间
├── 办公区
│   ├── 行政楼
│   └── 研发楼
└── 生活区
    ├── 食堂
    └── 宿舍
```
> 根区域主要用于统计单位的区域总量，和普通区域一样都是统计该区域里的表计总量。比如[首页](/pageFunction/SimpleDashboard)的统计


### 2.3 区域的关键字段

| 字段 | 作用 | 对统计的影响 |
|------|------|-------------|
| **区域名称** | 标识区域 | 在区域维度的报表中显示 |
| **父级区域** | 层级归属 | 决定区域树结构，支持逐级汇总 |
| **区域面积** | 建筑面积（m²） | 用于计算**单位面积能耗**指标 |
| **区域人数** | 常驻人数 | 用于计算**人均能耗**指标 |
| **绑定表计** | 关联计量设备 | 区域的能耗数据 = 所绑表计数据之和 |

### 2.4 区域与表计的关系

```
区域 "一车间"
├── 🔌 绑定电表 D II-01 （车间总电表）
├── 💧 绑定水表 S II-01 （车间总水表）
└── 🔥 绑定气表 Q II-01 （车间总气表）

一车间的总能耗 = 电表数据 + 水表数据 + 气表数据（经过因子折算后）
```

- 一个区域可以绑定**多块**表计
- 一块表计也可以绑定到**多个**区域
- 绑定后，表计的采集数据即纳入该区域的统计范围

### 2.5 月度统计数据

除能耗数据外，区域还支持录入**产值**等经济指标，用于计算：
- **单位产值能耗**（能耗 ÷ 产值）
- **能效对标**（实际单耗 vs 定额标准）

### 2.6 配置入口

进入 **管理中心 → [区域管理](/pageFunction/ManagementCenter/AreaManagement)**，创建区域层级并为每个区域绑定表计。

## 3. 因子设置

### 3.1 什么是因子

因子是将**不同能源品种的实物消耗量**统一折算为可比较、可汇总的标准值的换算系数。系统使用两类核心因子：

| 因子类型 | 作用 | 示例 |
|---------|------|------|
| **折标煤因子** | 将各类能源折算为**吨标准煤（tce）** | 1 kWh 电 ≈ 0.1229 kgce |
| **碳排放因子** | 将能源消耗转换为**CO₂ 排放量** | 1 kWh 电 ≈ 0.5810 kgCO₂ |

### 3.2 为什么需要因子

不同能源品种的计量单位不同——电是 kWh，水是 m³，天然气是 m³——无法直接相加。通过折标煤因子统一折算为标准煤后，才能汇总出「企业综合能耗」；通过碳排放因子折算后，才能统计「企业总碳排放」。

```
原始数据：       电 10,000 kWh  +  水 500 m³  +  天然气 2,000 m³    ❌ 无法直接相加
                    ↓                  ↓               ↓
折标煤因子：    × 0.1229          × 0.2571        × 1.3300
                    ↓                  ↓               ↓
标准煤：        1.229 tce     +   0.129 tce    +   2.660 tce    =   4.018 tce  ✅
```

### 3.3 因子分类

| 分类 | 包含能源品种 | 说明 |
|------|-------------|------|
| **化石能源** | 煤炭、天然气、柴油、汽油等 | 一次能源，碳排放较高 |
| **二次能源与综合动力** | 电力、蒸汽、压缩空气等 | 需考虑上游生产排放 |
| **耗能材质** | 自来水、工业用水等 | 主要计入取水/处理能耗 |

### 3.4 因子的关键字段

| 字段 | 说明 |
|------|------|
| **能源品种** | 适用的能源类型（如外购电力） |
| **折标煤系数** | 折算为标准煤的数值 |
| **碳排放因子值** | 折算为 CO₂ 的数值 |
| **核算标准** | 因子来源（国家标准 / 企业标准 / 自定义） |
| **执行状态** | 执行中 / 已停用（停用的因子不参与计算） |

> ⚠️ **注意**：修改因子值会影响所有历史数据的重新计算，请谨慎操作。建议通过**版本历史**功能追溯变更记录。

### 3.5 配置入口

进入 **管理中心 → [因子管理](/pageFunction/ManagementCenter/FactorManagement)**，维护折标煤因子和碳排放因子。

## 4. 统计逻辑

### 4.1 整体数据流

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  ① 表计采集  │ ──→ │  ② 数据存储  │ ──→ │  ③ 因子折算  │ ──→ │  ④ 多维汇总  │
│  原始读数    │     │  日/月用量   │     │  标准煤+碳排 │     │  区域/用途等  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

### 4.2 第一步：表计数据采集

系统通过配置的采集引擎（如大连思捷、手动抄表等）定时获取表计读数：

- **日用量** = 当日读数 − 前一日读数
- **月用量** = 月末读数 − 月初读数（或当月每日用量累加）
- **实际用量** = 读数差 × **倍率**

### 4.3 第二步：因子折算

每种能源的实物用量分别乘以对应的因子：

| 计算目标 | 公式 |
|---------|------|
| **折标准煤** | 能源用量 × 折标煤系数 |
| **碳排放量** | 能源用量 × 碳排放因子 |

以电能为例：
```
月用电量 10,000 kWh
→ 折标准煤：10,000 × 0.1229 = 1,229 kgce = 1.229 tce
→ 碳排放： 10,000 × 0.5810 = 5,810 kgCO₂ = 5.81 tCO₂
```

### 4.4 第三步：多维汇总

折算后的数据按照不同维度进行聚合：

#### 按区域汇总

```
父区域能耗 = Σ 子区域能耗（逐级向上汇总）

示例：
  一车间能耗 + 二车间能耗 = 生产区能耗
  生产区能耗 + 办公区能耗 + 生活区能耗 = 全厂总能耗
```

区域能耗 = 该区域下所有绑定表计折算后的**标准煤之和**（或碳排放之和）。

#### 按用途汇总

表计创建时可指定**用途**分类（工业、照明、空调、生活等），系统按用途维度分别统计：

```
工业用电 + 照明用电 + 空调用电 + 生活用电 = 总用电量
```

#### 按时间维度汇总

| 维度 | 说明 |
|------|------|
| **时** | 单块表计的分时用电量（需选择具体表计） |
| **日** | 每日用量汇总 |
| **月** | 月度用量汇总（最常用的统计周期） |
| **季** | 季度汇总 |
| **年** | 年度汇总，支持同比分析 |

### 4.5 统计校验与平衡

#### 层级平衡校验

系统会自动校验设备树中**上级表计读数 ≈ 下级表计读数之和**：

```
总表读数 ≈ 各分表读数之和（允许配置的误差范围）

若不相等 → 存在未计量支路或表计故障
→ 可创建虚拟表（公式计算表）补全差额
```


### 4.6 配置检查清单

在系统正式使用前，请确认以下配置项全部完成：

| 序号 | 检查项 | 验证方式 |
|------|--------|---------|
| 1 | 所有表计已录入并配置倍率、启表底数 | 设备管理页确认设备树完整 |
| 2 | 表计层级关系正确（父子级） | 设备架构页查看层级树 |
| 3 | 所有区域已创建并配置面积/人数 | 区域管理页确认区域树完整 |
| 4 | 每个区域已绑定对应的表计 | 区域详情页查看「区域表计」 |
| 5 | 折标煤因子已按能源品种配置 | 因子管理 > 折标煤因子 |
| 6 | 碳排放因子已按能源品种配置 | 因子管理 > 碳排放因子 |
| 7 | 因子执行状态均为「执行中」 | 确认无误停用的因子 |

完成以上配置后，即可在以下页面查看统计结果：
- **能源消费量**：按日/月查看综合能耗
- **能碳监控**：碳排放总量及趋势
- **能流分析（桑基图）**：可视化能流追踪
- **区域能耗排名**：各区域能耗对比
