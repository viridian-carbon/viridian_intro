# 碳资产

## 功能概述

碳资产模块用于企业碳资产的全面管理，涵盖 CEA（碳排放配额）和 CCER（国家核证自愿减排量）两大核心碳信用类型的核算、估值与交易管理。通过本模块，企业可以实时掌握碳资产的市值规模、盈亏状况、交易流水，并进行配额结算与交易登记，为碳市场参与提供数据支撑与决策依据。

## 核心功能

### 1. 顶部数据卡片

页面顶部提供 4 张核心数据卡片，一览碳资产全貌：
![alt text](碳资产(1).png)
#### 1.1 碳资产估值总额

| 字段 | 说明 |
|------|------|
| **总市值** | 企业碳资产的总估值（单位：元），含 CEA 和 CCER 合计 |
| **CEA 占比** | CEA 在总资产中的价值占比（%） |
| **CCER 占比** | CCER 在总资产中的价值占比（%） |
| **浮动盈亏** | 持仓碳资产因市场价格波动产生的未实现盈亏（元） |
| **已实现盈亏** | 已完成交易产生的已实现盈亏（元） |



#### 1.2 CEA（碳排放配额）

| 字段 | 说明 |
|------|------|
| **配额余量** | 当前剩余的碳排放配额数量（单位：t） |
| **资产市值** | CEA 对应的资产估值（单位：元） |



#### 1.3 CCER（自愿减排量）

| 字段 | 说明 |
|------|------|
| **自愿减排量** | 当前持有的 CCER 数量（单位：t） |
| **资产市值** | CCER 对应的资产估值（单位：元） |



#### 1.4 交易市场基准价

| 字段 | 说明 |
|------|------|
| **CEA 基准价** | 碳排放配额的市场基准价格（单位：元/t） |
| **CCER 基准价** | 自愿减排量的市场基准价格（单位：元/t） |
| **更新价格** | 点击此按钮可手动更新最新的市场基准价 |



### 2. 碳资产双维结构分析（左侧）

左侧区域展示两张环形图，从两个维度分析碳资产结构：
![alt text](碳资产(2).png)
#### 2.1 资金规模分布（RMB 资产市值）

以环形图展示各类碳信用资产的资金规模占比，反映资产的**价值结构**。


#### 2.2 碳信用存量分布（Tons 物理存量）

以环形图展示各类碳信用资产的物理存量占比，反映资产的**数量结构**。



### 3. 碳信用市场交易流水（右侧）

右侧区域为交易管理表格，记录所有碳信用的买卖交易明细。
![alt text](碳资产(3).png)
#### 表格字段说明

| 字段 | 说明 |
|------|------|
| **交易日期** | 交易发生的日期 |
| **标的类型** | 交易标的，如 CEA、CCER 等 |
| **交易方向** | 买入 / 卖出 |
| **交易数量(t)** | 本次交易的碳信用数量（吨） |
| **交易单价(¥/t)** | 每吨的交易价格（元） |
| **交易结算总额(¥)** | 交易总金额 = 交易数量 × 交易单价（元） |
| **备注说明** | 交易的补充说明信息 |
| **管理** | 操作列，支持编辑、删除等管理操作 |

#### 功能按钮

| 按钮 | 说明 |
|------|------|
| **年度配额结算** | 执行年度碳配额结算操作，核算年度配额使用情况 |
| **登记新交易** | 打开新交易登记表单，录入新的买卖交易记录 |
| **导出 Excel** | 将当前交易流水导出为 Excel 文件 |

## 使用指南

### 场景1：查看碳资产总览

1. 进入「碳资产」页面
2. 查看顶部**碳资产估值总额**卡片，了解总市值及盈亏状况
3. 查看 **CEA 卡片**和 **CCER 卡片**，了解各类型碳信用的余量与市值
4. 查看左侧**资金规模分布**和**碳信用存量分布**环形图，了解资产结构

### 场景2：更新交易市场基准价

1. 在顶部找到**交易市场基准价**卡片
2. 查看当前 CEA 和 CCER 的基准价
3. 点击「更新价格」按钮
4. 在弹出的对话框中输入最新的 CEA 和/或 CCER 市场基准价
5. 确认保存，系统将基于新价格重新计算资产估值

### 场景3：登记新的碳信用交易
![alt text](碳资产(4).png)
1. 在右侧交易流水区域，点击「登记新交易」按钮
2. 在弹出的表单中填写以下信息：
   - **交易日期**：选择交易发生日期
   - **标的类型**：选择 CEA 或 CCER
   - **交易方向**：选择买入或卖出
   - **交易数量**：输入交易吨数
   - **交易单价**：输入每吨价格
   - **交易结算总额**：自动计算（数量 × 单价）
   - **备注说明**：可选，填写交易备注
3. 确认信息无误后提交保存
4. 交易记录将出现在交易流水表格中，资产数据同步更新

### 场景4：执行年度配额结算
![alt text](碳资产(5).png)
1. 在交易流水区域点击「年度配额结算」按钮
2. 系统将根据年度内的排放数据与碳资产交易记录，自动核算年度配额使用情况
3. 查看结算结果，确认配额盈缺
4. 根据结算结果，决定是否需要进一步购入或出售碳信用

### 场景5：导出交易流水

1. 在交易流水区域点击「导出 Excel」按钮
2. 系统自动生成包含所有交易记录的 Excel 文件
3. 文件自动下载到本地，可用于存档或提交审计

### 场景6：管理已有交易记录

1. 在交易流水表格中找到目标交易记录
2. 点击「管理」列中的操作按钮
3. 支持**编辑**（修改交易信息）和**删除**（移除记录）操作
4. 编辑后资产数据将自动同步更新
