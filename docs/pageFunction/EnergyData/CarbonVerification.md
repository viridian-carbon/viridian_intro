# 碳排放核查

## 系统概述

碳排放核查用于对企业各类能源消耗产生的碳排放数据进行采集、核算与校验，帮助用户按照统一的核算标准梳理排放来源，形成可追溯、可审计的碳排放数据台账，为碳排放报告和减排决策提供可靠依据。

## 核心功能

### 1. 排放源管理

- 维护企业各类排放源信息（电力、水资源、天然气等）
- 为每个排放源配置对应的排放因子与核算方法
- 支持按区域、设备维度对排放源进行分类管理

### 2. 数据采集与核算

- 自动汇集各能源类型的消耗数据
- 按配置的排放因子进行碳排放量核算
- 统一折算为 CO₂ 排放量（吨）与标准煤折算量（吨）

### 3. 数据核查与校验

- 对采集数据进行完整性与异常值校验
- 标记缺失、超限或波动异常的数据，提示人工复核
- 支持对核查结果进行确认与留痕，保证数据可追溯

### 4. 核查报告

- 按周期（月度、季度、年度）生成碳排放核查报告
- 汇总各排放源的排放量与占比
- 支持导出报告数据，用于外部报送与存档

## 使用指南

### 发起核查

1. 登录系统后，进入"能源数据 - 碳排放核查"页面
2. 选择需要核查的区域与统计周期
3. 系统自动汇集数据并完成碳排放量核算

### 查看与确认核查结果

1. 在核查列表中查看各排放源的核算结果
2. 对系统标记的异常数据进行人工复核与确认
3. 确认无误后提交，生成对应周期的核查报告

### 导出核查报告

1. 在核查报告区域选择目标周期
2. 点击导出按钮，下载核查数据
3. 用于对外报送、审计或归档
